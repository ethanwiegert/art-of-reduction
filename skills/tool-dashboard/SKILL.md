# Instructions

After completing the database setup in `tool-tracking`, set up a very simple elegant dashboard that reads from `tool-tracking.db`. Use `strong-foundation` and start super simple and focus on functionality over design. Key is to display actionable data for the user to optimize AI usage or workflows. Start with a simple grouping by tool used. When you're finished start the local server for the site and simply tell the user "this is a simple foundation, can be modified as needed for you".
