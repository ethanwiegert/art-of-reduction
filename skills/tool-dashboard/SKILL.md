# Instructions

After completing the database set up in `tool-tracking` set up a very simple elegant dashboard based on what you know about the user.  Use `strong-foundation` and start super simple and focus on functionality over design.  Key is to display actionable data for the user to optimize AI usage or workflows.  Start with a simple grouping by tool used.  When you're finished start the local server for the site and simply tell the user "this is a simple foundation, can be modified as needed for you".
